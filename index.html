网络对时 如何保证时间准确

① 客户端 t0 = 发送时刻
→
② 服务器 t1 = 接收时刻
←
③ 服务器 t2 = 发送时刻
→
④ 客户端 t3 = 接收时刻
偏移 offset = ((t1 − t0) + (t2 − t3)) / 2 延迟 delay = (t3 − t0) − (t2 − t1)
自动对时：每 60 秒一次

    API 文档 把服务器时间接到你的程序里

    GET /api/now

    获取服务器当前时间快照（含毫秒时间戳、ISO 字符串、运行信息）。

    {
  "unix": 1787100000000,
  "iso": "2026-08-19T10:30:00.000Z",
  "utc": "Wed, 19 Aug 2026 10:30:00 GMT",
  "seconds": 1787100000,
  "server": { "hostname": "..." }
}
    GET /api/sync?t0=<发送时刻ms>

    NTP 风格四时间戳对时接口，返回 t0/t1/t2，配合本地 t3 可计算时钟偏移与网络延迟。

    {
  "t0": 1787100000000,   // 客户端发送时刻（回显）
  "t1": 1787100000123,   // 服务器接收时刻
  "t2": 1787100000124,   // 服务器发送时刻
  "receiveIso": "2026-08-19T10:30:00.123Z"
}
    UDP :123 · SNTP (RFC 4330)

    系统级对时协议。Windows 客户端可用 w32tm 直接同步到本服务器。

    # Windows（管理员）
w32tm /config /manualpeerlist:"localhost,0x8" /syncfromflags:manual /update
w32tm /resync

# 查看同步状态
w32tm /query /status
